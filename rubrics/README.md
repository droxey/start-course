# Rubrics

Generic rubrics you can drop into any course. Each one keeps the original rows, columns, score levels, and checkboxes. Copy the file you need into your course, then fill in the blanks.

| Rubric | Use it for |
| ------ | ---------- |
| [Writing & Blog Post Rubric](../rubrics/writing_blog_post_rubric.md) | Blog posts and other written work |
| [Presentation & Public Speaking Rubric](../rubrics/presentation_public_speaking_rubric.md) | Talks, demos, and final presentations |
| [Code Review Rubric](../rubrics/code_review_rubric.md) | Peer and instructor code reviews |
| [Coding Challenge Scoring Rubrics](../rubrics/coding_challenge_rubrics.md) | Coding challenges and the published technical article |
| [Project Rubric Template](../rubrics/project_rubric_template.md) | Any project: fill in the project name, passing score, and requirement rows |
| [Word Jumble Rubric (Example)](../rubrics/word_jumble_rubric_example.md) | A filled-in copy of the project rubric template |
| [Internship/Job Readiness Rubric](../rubrics/internship_job_readiness_rubric.md) | Career readiness check-ins with a coach |
| [Instructor Hiring Rubric](../rubrics/instructor_hiring_rubric.md) | Interviewing instructor candidates |

## How to Score

- Check each `☐` you can demonstrate. In your copy, change it to `☑`.
- Where a rubric says so, score each row 0 to 4 in 0.5 increments.
- Placeholders look like `<Project Name>`. Replace all of them before you publish.
